# 🍽️ Spice Delight Restaurant Website

This is a simple and responsive restaurant website created using **HTML, CSS, and JavaScript** as part of my **Web Development Internship – Task 1**.

## Features

* Responsive Navigation Bar
* Hero Section
* About Us
* Popular Dishes
* Food Gallery
* Chef Section
* Customer Testimonials
* Contact Section
* JavaScript Alert for "Reserve Table"
* Responsive Design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
Restaurant-Website/
│── index.html
│── style.css
│── script.js
│── images/
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser or run it using Live Server in VS Code.
