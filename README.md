# 🍽️ Spice Delight Restaurant Website

A modern, responsive, and interactive restaurant website built using **HTML5, CSS3, and JavaScript**. This project was developed as part of my **Web Development Internship** to demonstrate responsive web design, JavaScript DOM manipulation, and user-friendly UI/UX.

---

## 🚀 Features

### 🏠 Home Page
- Responsive Navigation Bar
- Mobile Hamburger Menu
- Hero Section with Call-to-Action Buttons
- Smooth Scrolling Navigation
- Sticky Navbar on Scroll

### 📊 Restaurant Highlights
- Animated Statistics Section
- About Us Section
- Why Choose Us Section

### 🍕 Menu
- Popular Dishes
- Order Now Buttons
- Food Gallery
- Today's Special Offers

### 👨‍🍳 Restaurant Information
- Meet Our Chef Section
- Customer Testimonials
- Opening Hours
- Google Map Location

### 📞 Contact
- Contact Form
- JavaScript Form Validation
- Email Format Validation
- Required Field Validation

### ✅ JavaScript Features
- Table Reservation Alert
- Food Order Alert
- Contact Form Validation
- Back-to-Top Button
- Sticky Navigation
- Dynamic Footer Year
- Mobile Navigation Toggle
- Restaurant Task Planner (Dynamic To-Do List using DOM Manipulation)
- Add & Delete Tasks Dynamically

### 📱 Responsive Design
- Mobile Friendly
- Tablet Friendly
- Desktop Friendly
- Flexbox Layout
- CSS Grid Layout
- Media Queries
